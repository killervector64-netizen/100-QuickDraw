=== QuickDraw100 Mobile Experimental Mod ===

Ini adalah usaha experiment untuk meniru mod "快速画符100%" milik tefeink di versi Mobile ACS.

CARA PAKAI:
1. Extract folder "ACS_QuickDraw100_Mobile" ini
2. Di game Mobile, buka MOD Store
3. Gunakan fitur "Fetch from GitHub / local" atau copy folder ke lokasi Mods game (tergantung cara install mobile)
4. Aktifkan mod
5. Restart game / load save

PERINGATAN PENTING:
- Mod ini EXPERIMENTAL.
- Kualitas Quick Draw 95% sering hardcoded di kode game, jadi Lua mungkin tidak bisa mengubahnya.
- Bisa jadi tidak bekerja sama sekali.
- Backup save kamu dulu sebelum mencoba.
- Jika tidak berhasil, saran terbaik tetap main di PC.
